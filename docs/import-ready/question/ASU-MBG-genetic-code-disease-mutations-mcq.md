## title
A stop-to-sense change explains an abnormally elongated beta-globin

## question
A 20-year-old anemic man is found to have an abnormal form of β-globin that is 172 amino acids long, rather than the 141 found in the normal protein. Which of the following point mutations is consistent with this abnormality?

## subject
fnd

## status
Draft

## owner
Admin team

## vignette
A 20-year-old man presents with anaemia. Laboratory analysis finds an abnormal beta-globin variant that is 172 amino acids long, versus the 141 residues of normal beta-globin.

## correct_answer
A

## answer_a
UAA → CAA

## explanation_a
Correct. UAA is the normal stop codon terminating beta-globin translation. Changing it to CAA (glutamine) converts a stop codon into a sense codon, so the ribosome reads straight through the former stop site instead of releasing the chain, continuing translation until it reaches the next in-frame stop codon further along the mRNA. This produces exactly the abnormality described — a beta-globin variant that is longer than normal (172 versus 141 residues) rather than shorter — the same mechanism responsible for real haemoglobin variants such as Hb Constant Spring.

## answer_b
UAA → UAG

## explanation_b
Incorrect. This changes one stop codon into a different stop codon — translation still terminates at the same position, so the protein length would be unchanged, not elongated to 172 residues.

## answer_c
CGA → UGA

## explanation_c
Incorrect. This changes a sense codon (CGA, arginine) into the stop codon UGA — a nonsense mutation that would terminate translation early, producing a shorter, truncated protein, not a longer one.

## answer_d
GAU → GAC

## explanation_d
Incorrect. Both GAU and GAC code for aspartate — this is a silent mutation with no effect on the protein sequence or length at all, so it cannot explain an elongated variant.

## answer_e
GCA → GAA

## explanation_e
Incorrect. This is a missense change (alanine to glutamate) at one internal codon — it substitutes one amino acid for another without changing the protein's length, so it cannot explain a 172-versus-141-residue difference.

## title
An anticodon of GUA reads a tyrosine codon

## question
What amino acid is carried by a tRNA with the anticodon, GUA?

## subject
fnd

## status
Draft

## owner
Admin team

## vignette

## correct_answer
B

## answer_a
Valine

## explanation_a
Incorrect. This would be the amino acid if GUA were read directly as a codon (GUA does code for valine) — but the question gives an anticodon, not a codon, and an anticodon must be matched antiparallel to the mRNA codon it pairs with before looking up the amino acid.

## answer_b
Tyrosine

## explanation_b
Correct. An anticodon pairs antiparallel to its mRNA codon, so anticodon 5'-GUA-3' pairs with codon 5'-UAC-3' (reading the codon, as always, 5' to 3'). Looking up UAC on the codon table gives tyrosine, so this tRNA carries and delivers tyrosine wherever a UAC (or, via wobble, UAU) codon appears in the reading frame.

## answer_c
Methionine

## explanation_c
Incorrect. Methionine's only codon is AUG, which does not correspond to the anticodon GUA when paired antiparallel — the correct answer requires reverse-complementing GUA to reach the actual mRNA codon it recognises.

## answer_d
Alanine

## explanation_d
Incorrect. Alanine's codons (GCU, GCC, GCA, GCG) do not correspond to the anticodon GUA when paired antiparallel.

## question
From the Codon table, if this sequence UAUGAGCAG is mutated to UAUGUGCAG, what is the type of this mutation?

## subject

## status

## vignette

## correct_answer
D

## answer_a
Silent mutation

## explanation_a
Incorrect. A silent mutation would leave the encoded amino acid unchanged — here the second codon changes from GAG (glutamate) to GUG (valine), a different amino acid, so the mutation is not silent.

## answer_b
Frame shift mutation

## explanation_b
Incorrect. No bases were inserted or deleted — a single base within the second codon was substituted (GAG to GUG), leaving the reading frame and the length of the sequence unchanged, so this is not a frameshift.

## answer_c
Nonsense mutation

## explanation_c
Incorrect. A nonsense mutation converts a sense codon into a stop codon — GUG is valine, a normal sense codon, not a stop codon, so translation is not terminated early here.

Missense mutation

## explanation_d
Correct. This is the definition of a missense mutation, and this exact Glu-to-Val substitution is the same change responsible for sickle cell haemoglobin.

## title
64 codons exist because 4 bases fill 3 codon positions

## question
The reason there are 64 possible codons is most likely which one of the following?

## subject
fnd

## status
Draft

## owner
Admin team

## vignette

## correct_answer
B

## answer_a
There are 64 aminoacyl tRNA synthetases

## explanation_a
Incorrect. There are roughly 20 aminoacyl-tRNA synthetases (one family per amino acid), not 64 — the number of synthetases has no bearing on how many codons the genetic code contains, and reverses cause and effect.

## answer_b
There are four possible bases at each of three codon positions

## explanation_b
Correct. A codon is a triplet, and each of its three positions can independently be any one of the four bases (A, U, G or C). The total number of possible triplets is therefore 4 x 4 x 4 = 64, which is exactly why the genetic code has 64 codons — 61 sense codons plus 3 stop codons.

## answer_c
Each base is able to participate in wobbling

## explanation_c
Incorrect. Wobble describes flexible pairing at a codon's third position during translation, which is why one tRNA can sometimes read more than one codon — it does not determine how many codons exist in the code in the first place, which follows purely from 4 bases across 3 positions.

## answer_d
All possible reading frames can be used this way

## explanation_d
Incorrect. The genetic code is read in one fixed reading frame at a time, not simultaneously in all possible frames — the 64-codon count comes from the 4-bases-by-3-positions combinatorics, not from reading multiple frames.

## answer_e
The more codons, the faster protein synthesis can be accomplished

## explanation_e
Incorrect. The number of codons has no direct relationship to translation speed; 64 is simply the combinatorial total of 4 possible bases across 3 codon positions.

## title
A mischarged tRNA still pairs by its anticodon, not its cargo

## question
A tRNA molecule that is supposed to carry cysteine (tRNAcys) is mischarged, so it carries alanine (ala-tRNA cys). What will be the fate of this alanine residue during protein synthesis?

## subject
fnd

## status
Draft

## owner
Admin team

## vignette

## correct_answer
B

## answer_a
It will be incorporated into a protein in response to an alanine codon

## explanation_a
Incorrect. The tRNA's anticodon is unchanged and still specifically recognises cysteine codons, not alanine codons — the ribosome pairs codon to anticodon, and this mischarged tRNA's anticodon is a cysteine anticodon regardless of which amino acid it happens to be carrying.

## answer_b
It will be incorporated into a protein in response to a cysteine codon

## explanation_b
Correct. This is the adaptor hypothesis: the ribosome reads only the tRNA's anticodon against the mRNA codon — it has no way to check which amino acid is actually attached. Since this tRNA's anticodon is still the normal cysteine anticodon, it will pair with cysteine codons exactly as usual and deliver its cargo there, incorporating alanine at what should have been a cysteine position in the growing protein.

## answer_c
It will remain attached to the tRNA, as it cannot be used for protein synthesis

## explanation_c
Incorrect. Nothing about the ribosome-mRNA-tRNA system detects or blocks a mischarged amino acid — the classic experiment demonstrating the adaptor hypothesis specifically showed that a mischarged tRNA is used normally, not rejected.

## answer_d
It will be incorporated randomly at any codon

## explanation_d
Incorrect. Incorporation is not random — it is governed by the same specific codon-anticodon pairing rule that governs every other tRNA, which is exactly why the mischarged alanine ends up specifically at cysteine codon positions, not scattered randomly.

## answer_e
It will be chemically converted to cysteine by cellular enzymes

## explanation_e
Incorrect. No cellular mechanism converts one amino acid into another once it is attached to a tRNA; the alanine remains alanine and is incorporated as alanine, just at the wrong (cysteine-coded) position.

## question
A base substitution mutation in a gene sometimes has no effect on the protein the gene codes for. Which of the following factors could account for this?

## subject
fnd

## status
Draft

## owner
Admin team

## vignette

## correct_answer
B

## answer_a
the rarity of such mutations

## explanation_a
Incorrect. How rare a mutation is has no bearing on whether, when it does occur, it changes the encoded protein — rarity is a frequency statement, not a mechanism that could make a substitution silent.

some amino acids have more than one codon

## explanation_b
Correct. This is codon degeneracy: most amino acids are specified by more than one codon, often differing only at the third, "wobble" position. A and B

Incorrect. This combines the correct factor (B, codon degeneracy) with an incorrect one (A, rarity, which does not explain why a mutation that does occur would have no effect) — since A does not hold up, this combined answer is wrong.

A, B and C

## explanation_e
Incorrect. This combines one correct factor (B) with two incorrect ones (A, rarity; C, a non-existent mRNA self-correcting mechanism) — since A and C do not hold up, this combined answer is wrong.
