# Arabic renderings that need a native reviewer

The five Year-1 glossaries (514 terms) were written from the department books
in English; the Arabic term and definition were supplied by the authoring lanes.
Most use the standard Egyptian medical-Arabic equivalents. The entries below
are the ones each lane flagged as transliterated, descriptive, or otherwise not
verified as *the* canonical classroom term. A reviewer should confirm or replace
the `ar` field; the `definition_ar` text is not in question.

## 101 ISK — `101-ISK-glossary.md`
- diapedesis → الحَدَل (classical; "الانسلال" also circulates)
- glycocalyx → الغليكوكاليكس (transliteration)
- cristae → عُرف الميتوكوندريا (descriptive)
- euchromatin / heterochromatin → يوكروماتين / هيتروكروماتين (transliterations)
- rouleaux formation → تكوّن الرولو (transliteration)
- hyalomere → الهيالومير (transliteration)
- merocrine secretion → الإفراز الميروكريني (transliteration)
- desmosome → الديسموسوم (transliteration)
- capacitation → اكتساب القدرة الإخصابية (descriptive)
- gastrulation → تكوّن المعيدة (descriptive; "الغسترلة" also seen)
- vernix caseosa → المادة الدهنية الجبنية (descriptive; "الفيرنكس" also common)
- diaphysis → جسم العظم الطويل (descriptive; "الجَدل" is the single-word alternative)
- extensor expansion → الرداء الباسط للإصبع (coinage)
- thenar space → الفراغ الراحي الوحشي (coinage)
- flexor / extensor retinaculum → الرباط الرسغي القابض / الباسط ("الشبكية القابضة/الباسطة" also used)
- porter's tip deformity → تشوّه يد الشيّال (descriptive)

## 108 INT — `108-INT-glossary.md`
- cloudy swelling → التورم الغائم للخلية (descriptive)
- caspase (id `caspase-108`) → إنزيم الكاسباز (transliteration)
- pyknosis → التقلص النووي ("بيكنوزس" also used)
- primary hemochromatosis → داء ترسب الأصبغة الدموية الأولي ("الهيموكروماتوزيس" also common)
- bronze diabetes → السكري البرونزي (literal)
- signet ring appearance → مظهر خاتم الفص (descriptive)
- antagonist → الضاد ("المضاد" is the other common choice)
- potency / efficacy → القوة الدوائية / الكفاءة (sources inconsistent on the pair)
- receptor down-regulation → تخفيض تنظيم المستقبلات (descriptive)
- tachyphylaxis → التعود السريع ("تاكيفيلاكسيا" also plausible)
- idiosyncrasy → الاستجابة الشاذة الوراثية (descriptive)
- iatrogenic disease → المرض المنشأ طبياً (descriptive)
- ion trapping → احتباس الأيونات (descriptive)
- kary(o)- / -lysis → الجذر اللغوي كاريو / اللاحقة الدالة على التحلل (affixes, necessarily descriptive)

## Terms deliberately left out
Each lane also listed book-supported terms it cut to stay within budget, and a
handful the book names without defining (e.g. reticulocyte, hexokinase,
operon — not actually in the 102 book; lung volumes in 104 appear only as
diagram labels; in 103 the adductor-compartment nerve heading on p.22 is
overprinted and unreadable). Those lists are in the lanes' reports and can seed
a second glossary pass; none was omitted for lack of a source.
