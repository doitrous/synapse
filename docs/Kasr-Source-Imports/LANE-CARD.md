# LANE-CARD — Kasr Al Ainy Year 1 (kau)
Read this card first. Open the full manual, `LANE-BRIEF.md` or `HANDOFF.md` only when you hit a wall; name the wall in your report.

## 1. Identity and ids
University id `kau`. Years `KAU_Y1`…`KAU_Y5`. **Module ids are bare, no prefix** — Kasr predates the university-prefix rule: `101 ISK`, `102 INT`, `103 BMS`, `104 CPS`, `108 INT`. Concept id `CON-<SYSTEM>-<14 hex>` from `mintConceptId(module, subject, canonical_key[, system])` in `scripts/kasr/seeds/types.ts:429` — **module-salted**: the hash is `sha256("kau:<module>:<key>")`, so the same idea in two Kasr modules mints two different concept ids (a real duplicate §4 must catch, not a bug). Question id (generated) from `build-batches.ts`; hand-authored `QST-<SUBJ>-<SLUG>-<NNN>`. Files: `docs/Kasr-Source-Imports/{concept,article,question,written,practical,evidence,relations,glossary,coverage,academic,media-requests}/`.

## 2. The ten rules that cannot bend
Same ten as every lane (`Instruction Manual for Content Creation/LANE-CARD-TEMPLATE.md` §2), plus: the book is the source — a definition/answer not in the cached page text is left blank with a `field_notes` reason, never filled from model knowledge (`LANE-BRIEF.md` rule 1). Six tags here collapse to one university (`kau`) but still all six columns.

## 3. Read text, don't look at pictures
Per-source page cache already exists at `scripts/kasr/extract/pagetext/<sourceId>.json` (find the id in `docs/Kasr-Source-Imports/manifest/kasr-y1-sources.json`) — read that first; only fall back to `node scripts/content/pagetext.mjs show "<pdf>" --pages a-b` for a source not yet in that cache. Garbled/highlighted keys: render at 200–300 dpi and read by eye, never trust `-layout` text alone (`kasr-pdf-extraction-traps`).

## 4. Author: Kasr keeps its own generator
**Do not use `scripts/content/emit-mcq.mjs` for Kasr.** Author seeds in `scripts/kasr/seeds/*.ts` (see `mcq.ts`, `101-eoy-2024.ts` for the shape), then generate:
```
node --experimental-strip-types scripts/kasr/build-batches.ts "<module>"
```
`<module>` is one of `"101 ISK"`, `"102 INT"`, `"104 CPS"` (103 BMS and 108 INT are hand-authored, no generator) — **there is no build-everything mode**; a bare run refuses with "name the module to build" because five lanes share this one script and a bare run once rewrote every module's batches, including another lane's finished work. Then gate every file you touched, naming every sibling concept/article file of the module with `--with` (list them: `ls docs/Kasr-Source-Imports/{concept,article}/<module-slug>-*.md`):
```
node scripts/content/gate.mjs batch <file> --with <every sibling concept/article file>
node scripts/content/gate.mjs simulate <all your module's concept/article/evidence/question/written files>   # positional, apply order — no --with
```

## 5. Progress ledger
Kasr has no seed-JSON directory `ledger.mjs` can read (seeds are TypeScript, not JSON). Progress is the module's own `coverage/<module>-coverage.md` / `docs/Kasr-Source-Imports/HANDOFF.md`. Do not run `content:ledger` here; it will find nothing.

## 6. Commit rhythm
First commit within minutes; commit + push every 5–10 questions. Author only — never `git commit`/`push`/import beyond your own branch push per the 2026-08-27 rule (Omar: subagents push their own gate-clean work to their branch). Report ≤ 20 lines, ends `HANDOFF: <branch>@<sha> · resume-first: <next>`.

## 7. This lane's known traps
- **`removeOrphans` / `--sweep` is forbidden.** Deletes any hand-authored batch the current generator run did not itself produce — has destroyed work three times, most recently `108 INT written/` twice.
- **Whole-module regeneration drops hand-applied tags.** Regenerating a module's MCQ batch does not preserve `resource_ids` a later pass hand-applied on top — verify with a before/after id-set diff (`comm -23`) and re-apply, or fold tagging into generator input instead.
- **Never edit a file whose header says `Generated by scripts/kasr/build-batches.ts`.** Create a hand-authored file beside it.
- A generator's own `existingConceptIds()` dedup check can be blind to concepts minted by the written-paper pipeline and to other-year catalogues — grep the target subject's live concepts and written batches directly before minting from inside a generator.
- "Live state" for `medical:simulate`/`find-existing.mjs` is a 10-day-old snapshot (`server/data/medical-library-v1.json`, 2026-08-12) — anything imported since is invisible; write sparse update rows only.
- `[clear]` never belongs in a text/prose column, only list columns — verify with `node --experimental-strip-types scripts/kasr/check-column-parsers.ts <file>`.
- `subject` must be one of the 20 catalogue ids (`renal` not `ren`, `neuro` not `neu`); `pharm` concepts must name an explicit body-system (`FND` or `INF`) — the mint refuses `pharm` alone.
