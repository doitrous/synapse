## label
The genetic code is specific: each codon specifies exactly one amino acid

## canonical_key
translation.codons.specificity-one-aa-per-codon

## definition
The genetic code's specificity means each individual codon designates exactly one amino acid (or a stop signal) -- never more than one. This is distinct from degeneracy, which runs the other way: several different codons can specify the same amino acid, but a single given codon is never ambiguous about which one amino acid it calls for.

## explicit_objective
State that each codon specifies exactly one amino acid, which is what makes the genetic code specific (unambiguous) rather than ambiguous.

## pitfalls
Confusing specificity (one codon -> one amino acid) with degeneracy (one amino acid <- several possible codons) -- the two properties run in opposite directions and both are true of the code simultaneously.

## label
Codons are carried on mRNA, not on the DNA template strand, tRNA or rRNA

## canonical_key
translation.codons.location-on-mrna

## definition
A codon is, by definition, a three-base unit of messenger RNA sequence. The DNA template strand carries the complementary information from which mRNA is transcribed, but its triplets are not themselves called codons; tRNA carries the complementary anticodon that pairs with an mRNA codon, and rRNA is a structural/catalytic ribosomal component, not the molecule whose triplets are read during translation.

State that codons are the three-base units read on mRNA during translation, not on the DNA template strand, tRNA or rRNA.

## pitfalls
Calling the matching DNA template-strand triplet a "codon" -- that term is reserved for the mRNA sequence actually read by the ribosome.

## label
The growing polypeptide is released from the ribosome when a chain-terminating codon is reached

## canonical_key
translation.termination.release-at-stop-codon

## definition
Elongation continues codon by codon until a chain-terminating (stop) codon enters the ribosomal A site; there, a release factor (rather than any tRNA, since none pairs with a stop codon) triggers hydrolysis of the bond linking the finished polypeptide to the last tRNA, releasing the completed protein from the ribosome.

## explicit_objective
State that the growing polypeptide chain is released from the ribosome when a chain-terminating codon is reached.

## pitfalls
Inventing a "chain-terminating tRNA" that binds the stop codon -- termination is carried out by a release factor, not by any tRNA, and mRNA-cap or poly(A)-tail landmarks play no direct role in triggering release.

## label
The genetic code is degenerate: 64 codons encode only 20 amino acids

## canonical_key
genetic-code.degeneracy.definition-64-codons-20-aa

## definition
With 4 possible bases at each of 3 codon positions, there are 64 possible codons, but only 20 naturally occurring amino acids are encoded (plus stop signals) -- so most amino acids are specified by more than one codon. This redundancy is called degeneracy, and it is distinct from the code's non-overlapping, contiguous reading and from any notion of overlapping codons.

## explicit_objective
State that the genetic code being degenerate means most of the 20 amino acids are each encoded by more than one of the 64 possible codons.

## pitfalls
Confusing degeneracy (multiple codons per amino acid) with overlapping reading (which the genetic code does not use) or with a made-up term like "duplicative".
