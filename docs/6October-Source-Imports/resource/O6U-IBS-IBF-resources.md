## description
A Moodle quiz-results export of the BOS 101 (combined Body Structure / Body Function)
mid-module exam, module 1, October sitting: 25 single-best-answer questions, each printing
"<pct>% of respondents (<n> of <total>) answered this question correctly" beneath the stem
and a per-option respondent count, from which the printed-correct option is recovered by
matching the option whose count equals <n> (see docs/6October-Source-Imports/coverage/O6U-IBS-IBF-triage.md).
~218–222 respondents per question. Covers cytology/histology, general chemistry and
biochemistry, osteology and joint terminology, and autonomic pharmacology basics.
