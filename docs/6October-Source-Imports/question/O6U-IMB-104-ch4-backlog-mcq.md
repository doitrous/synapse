## title
The statement that is NOT a characteristic of the genetic code

## question
Which of the following statements is NOT a characteristic of the genetic code?

## subject
fnd

## status
Draft

## owner
Claude

## vignette

## correct_answer
D

## answer_a
Each codon consists of three bases.

## explanation_a
Incorrect (i.e. this IS a true characteristic). A codon is, by definition, a triplet of three mRNA bases.

## answer_b
A single amino acid can have more than one codon.

## explanation_b
Incorrect (i.e. this IS a true characteristic). This is the code's degeneracy: several codons can specify the same amino acid.

## answer_c
The genetic code is mainly universal.

## explanation_c
Incorrect (i.e. this IS a true characteristic). With rare exceptions (such as some mitochondrial codes), the genetic code is essentially universal across organisms.

## answer_d
A single codon can code for more than one amino acid.

## explanation_d
Correct. The genetic code is specific: each individual codon designates exactly one amino acid (or a stop signal), never more than one. Confusing this with degeneracy -- where one amino acid can be encoded by several different codons -- reverses the direction of the relationship. So a single codon coding for more than one amino acid is not a real feature of the code, making it the false statement asked for here.

## title
What post-translation processing includes

## question
Post-translation processing includes:

## subject
fnd

## status
Draft

## owner
Claude

## vignette

## correct_answer
D

## answer_a
5' capping.

## explanation_a
Incorrect. 5' capping is added to the primary transcript co-transcriptionally, an mRNA-processing event, not a post-translational (protein-level) one.

## answer_b
3' polyadenylation.

## explanation_b
Incorrect. Polyadenylation adds the poly(A) tail to the 3' end of the transcript, again an mRNA-processing step rather than a modification of the finished protein.

## answer_c
Splicing.

## explanation_c
Incorrect. Splicing removes introns from the pre-mRNA before translation; it acts on the transcript, not on the translated protein.

## answer_d
Trimming.

## explanation_d
Correct. Proteolytic trimming -- cleavage of a precursor polypeptide into its mature, active form (as with proinsulin becoming insulin) -- genuinely acts on the protein product after translation. Capping, polyadenylation and splicing, by contrast, are all mRNA-level processing events that occur before or during transcription/translation, not modifications of the finished protein itself. This makes trimming the one option that is truly "post-translational".

## title
Result of inserting or deleting one or two bases

## question
Insertion or deletion of one or two bases in a gene results in:

## subject
fnd

## status
Draft

## owner
Claude

## vignette

## correct_answer
C

## answer_a
Missense mutation.

## explanation_a
Incorrect. A missense mutation is a base substitution that changes one codon to specify a different amino acid; it does not shift the reading frame the way an indel does.

## answer_b
Silent mutation.

## explanation_b
Incorrect. A silent mutation is a substitution that leaves the amino acid sequence unchanged; it is not what an indel of this size produces.

## answer_c
Frame shift mutation.

## explanation_c
Correct. Because the ribosome reads mRNA in non-overlapping triplets, inserting or deleting a number of bases that is not a multiple of three -- such as one or two bases -- shifts every downstream codon boundary. This scrambles the entire reading frame from that point onward, usually producing a garbled or prematurely truncated protein, which is exactly what defines a frameshift mutation.

## answer_d
Nonsense mutation.

## explanation_d
Incorrect. A nonsense mutation is a substitution that changes a codon into a premature stop codon; it is a distinct category from a frame-shifting indel, although a frameshift can secondarily create a premature stop somewhere downstream.

There, a release factor -- rather than any tRNA, since none pairs with a stop codon -- triggers hydrolysis of the bond linking the finished polypeptide to the last tRNA, releasing the completed protein from the ribosome.

## answer_b
A chain terminating tRNA binds to the ribosome.

## explanation_b
Incorrect. There is no "chain terminating tRNA" -- stop codons have no matching tRNA at all; termination is carried out by a release factor.

## answer_c
The 7-methyl guanosine cap is reached.

## explanation_c
Incorrect. The 7-methylguanosine cap sits at the 5' end of the mRNA and plays no direct role in triggering release of the finished protein.

## answer_d
The poly A tail is reached.

## explanation_d
Incorrect. The poly(A) tail sits at the 3' end of the mRNA, well past the stop codon in most transcripts, and does not itself trigger polypeptide release.

## title
What 64 codons encoding 20 amino acids illustrates

## question
While the genetic code has 64 codons, there are only 20 naturally occurring amino acids. Consequently, some amino acids are encoded by more than one codon. This feature of the genetic code is an illustration of the genetic code being:

## subject
fnd

## status

## owner

## vignette

## correct_answer
A

## answer_a
Degenerate

## explanation_a
Correct. With 4 possible bases at each of 3 codon positions, there are 64 possible codons, but only 20 naturally occurring amino acids -- so most amino acids are specified by more than one codon. This redundancy is precisely what "degenerate" means when describing the genetic code.

## answer_b
Duplicative

## explanation_b
Incorrect. "Duplicative" is not the standard term used to describe this redundancy; the correct term is degenerate.

## answer_c
Nonoverlapping

## explanation_c
Incorrect. Non-overlapping describes how the code is read (each base belongs to only one codon), a separate property from the redundancy of multiple codons per amino acid.

## answer_d
Overlapping

## explanation_d
Incorrect. The genetic code is specifically non-overlapping, not overlapping -- and even if it were overlapping, that would not describe multiple codons encoding the same amino acid.
