# Concept & article authoring style (student-readability pass)

Standard for the readability fix Omar asked for (2026-09-05): brief concept
titles, digestible paragraphs, and scannable emphasis. Applies to **every**
concept (`## label` / `## definition`) and **every** library article body.

## 1. Concept `label` = a brief title, not a sentence
- A short noun phrase that names what the concept IS — ideally ≤ 8 words.
- The `canonical_key` is usually the ready-made basis: humanize it.
  - `plasma-proteins-formation-and-functions` → **"Plasma proteins: formation and functions"**
  - `eosinophil-versus-neutrophil-light-microscopy` → **"Eosinophils vs neutrophils on a film"**
- NOT the old style: a full run-on sentence stating the whole answer.

## 2. Concept `definition` = 2–4 short paragraphs
- Separate paragraphs with a blank line (`\n\n`). The popover now splits on
  newlines and renders each as its own paragraph (`ConceptText`).
- Each paragraph = one idea, 1–3 sentences. Lead with the core fact; put
  mechanism, then clinical/relevance, in later paragraphs.
- Keep all the facts — reorganize and break up, don't delete substance.

## 3. Library article body = same short paragraphs
- Article bodies already split on newlines into paragraphs (`Library.tsx`).
  One idea per paragraph; break up any wall of text.

## 4. Emphasis for scanning (renders now)
- `**bold**` → bold. Use it for the **key terms** a student scans for
  (the named structure, the number that matters, the answer word).
- `__underline__` → underline. Use it sparingly for the ONE most important
  takeaway in a paragraph — over-underlining defeats the purpose.
- `*italic*` and `` `code` `` also render. No raw HTML — the renderer only
  understands these tokens (`src/lib/inlineMarkup.ts`).
- A single underscore in an identifier (`SYS_HEM_T01`, `SUB_PE`) is safe — only
  paired `__like this__` underlines.

## 5. Which layer to edit (do NOT get wiped)
- **Generated Kasr concepts** — the 4 files whose header says "Generated by
  scripts/kasr/build-batches.ts" (101 ISK, 102 INT, 103 BMS, 104 CPS families):
  edit the **seed** in `scripts/kasr/seeds/…`, then rebuild THAT module only and
  `git diff` before trusting (the toolchain is shared; a broad rebuild can wipe
  hand-authored `written/` batches — never run a registry/removeOrphans step).
- **All other concept/article batches** (authored directly, other universities):
  edit the `docs/import-ready/{concept,article}/*.md` file in place.
- Change ONLY `label`, `definition`, and article body text. Never touch ids,
  `canonical_key`, marks, tags, exam signals, or question content.

## Worked example (gold standard)
`scripts/kasr/seeds/mcq/102-INT/plasma-proteins.ts` — label shortened to
"Plasma proteins: formation and functions"; definition split into four
paragraphs (sources → osmotic role → other functions → clinical) with **bold**
key terms and __underlined__ takeaways. Same content, scannable shape.
