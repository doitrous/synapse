- Never enter credentials, never accept/decline any prompt beyond normal Telegram Web UI.
- Downloads land in `~/Downloads`. Before downloading, check both `~/Downloads` and the
  corpus (`/Users/doitrous/Desktop/helwan/...`) for an existing file of the same or a
  similar name — do not re-download what is already filed.
- Do **not** download video or audio (`.mp4`, `.mp3`, `.m4a`). Documents/PDFs/images only.
- File every download under the **target folder** named in the tables above, using the
  **filename prefix** given (or no prefix, where the table says so).
- Record every fetched file in
  `docs/Helwan-Source-Imports/manifest/telegram-fetch-log.md` as a row:
  `link → saved path → sha256`. Create that log file if it does not yet exist.
- The moment the slot ends (time limit reached, or the list above is exhausted), report
  "browser free" to the orchestrator immediately — do not keep browsing on unlisted links
  or channels "while already in there."
