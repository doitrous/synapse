## label
Pseudoparasites, coprozoic organisms and spurious parasites are non-infecting artefacts of stool or specimen examination, not true infections: a pseudoparasite is any object or organism mistaken for a parasite; a coprozoic organism is a free-living species passing through the alimentary tract undigested; and a spurious finding is another species' parasite stage, ingested (e.g. in undercooked meat), passed unchanged in stool without ever having infected the examined host

## arabic_label
الطفيليات الكاذبة والعضويات البرازية والعدوى الزائفة

## arabic_aliases

## definition
Three related terms describe a stool or specimen finding that looks like infection but is not. A pseudoparasite is any artefact or non-parasitic object (a plant fibre, a food particle, a free-living mite) that could be mistaken for a genuine parasite on microscopic examination. A coprozoic organism is a free-living (non-parasitic) species -- often a free-living protozoan or nematode from the environment -- that passes through the human alimentary tract without infecting the host and is found, still identifiable, in a stool sample. A spurious parasitic finding is subtly different again: it is a genuine parasite stage of another host species (for example, an animal liver fluke's eggs, ingested by eating that animal's raw or undercooked liver) that survives transit through the human gut and appears in the stool unchanged, without the human ever having been truly infected. All three are grouped together because each can cause a false-positive parasitological diagnosis if not recognized.

## explicit_objective
Distinguish pseudoparasites (mistaken-identity artefacts), coprozoic organisms (free-living species passing through undigested) and spurious findings (another species' parasite stage passed unchanged after ingestion) as three related, non-infecting causes of a false-positive stool examination.

## pitfalls
Treating "spurious" and "coprozoic" as fully interchangeable -- both describe organisms passing through the gut without infecting, but a coprozoic organism is free-living by nature, while a spurious finding is a genuine parasite of a different host species that was ingested, not a free-living organism.

## id
CON-INF-7302E7FA7F9A30

## label
An incidental (accidental) parasite establishes itself in a host species other than its ordinary one; an erratic (aberrant) parasite instead wanders to a body site other than its normal one, within the correct host species

## canonical_key
teaching.parasitology.foundations.incidental-vs-erratic-parasite

## aliases
Incidental parasite
Erratic parasite
Aberrant parasite

## arabic_label
الطفيلي العرضي مقابل الطفيلي الشارد

## arabic_aliases
طفيلي عرضي في عائل غير معتاد
طفيلي شارد في موضع غير معتاد

## definition
Two parasitology terms are easily confused because both describe a parasite "somewhere it should not be," but they differ in which axis is wrong. An incidental (accidental) parasite is one that establishes itself in a host species other than its ordinary one -- the WRONG HOST, as when an animal parasite occasionally infects a human. An erratic (aberrant) parasite, by contrast, occurs in the CORRECT host species but wanders to a body site (organ or tissue) other than the one it normally occupies -- for example, an intestinal parasite's larva ending up in the liver or lung of its usual host. The distinction matters clinically: an incidental infection raises the question of why an unusual host was infected, while an erratic infection raises the question of why the parasite is in an unusual location within its usual host.

## explicit_objective
Distinguish an incidental (accidental) parasite, which infects a host species other than its ordinary one, from an erratic (aberrant) parasite, which occurs in the correct host but in an abnormal body site.

## pitfalls
Confusing "wrong host" (incidental) with "wrong site within the right host" (erratic) -- both terms describe a parasite in an unexpected place, but the axis of unexpectedness (host species vs. body location) differs.

## label
A parasite's life cycle can involve several host roles: the definitive host harbours the adult/sexual stage; the intermediate host is where all larval development takes place; the paratenic (transfer) host carries the organism in an arrested state of development, without further development, transporting it onward; and a reservoir host is a non-human animal harbouring the same parasite, serving as an additional source of human infection

## canonical_key

## aliases

Intermediate host
Paratenic host
Transfer host
Reservoir host

## arabic_label
أنواع العوائل في دورة حياة الطفيلي

## arabic_aliases
العائل النهائي
العائل الوسيط
العائل الناقل
العائل المستودع

## definition
A parasite's life cycle can distribute across several distinct host roles. The definitive (final) host harbours the parasite's adult or sexual reproductive stage. The intermediate host is where all of the parasite's larval developmental stages take place, before it becomes infective for the next host. The paratenic host -- also called a transfer host -- harbours the parasite in an arrested state of development: no further maturation happens there, but the host carries the organism onward, propagating it from one place to another until it reaches a host in which development can resume or the definitive host is reached. A reservoir host is an animal other than humans that harbours the same parasite species that infects humans, without itself necessarily being diseased, and thereby serves as an additional source from which humans can become infected.

## explicit_objective
Distinguish the definitive host (adult/sexual stage), intermediate host (larval development), paratenic/transfer host (arrested development, carries the organism onward) and reservoir host (non-human host, additional infection source) as the distinct roles a host can play in a parasite's life cycle.

## pitfalls
Confusing the paratenic (transfer) host, in which the parasite's development is arrested and it is merely carried onward, with the intermediate host, in which active larval development occurs -- both hosts are non-definitive, but only the intermediate host is where the parasite actually matures further.
