# Item

## id
QST-AUNINI105-INI-MCQ-CH8-Q002

## title
Pseudoparasite mistaken for a parasite

## question
Type of parasite that could be mistaken as parasite during examination?

## subject
inf

## status
Draft

## owner
Claude

## vignette

## correct_answer
D

## answer_a
Obligate

## explanation_a
Incorrect. An obligate parasite is one that cannot live outside a host at all -- a dependency category, not a mistaken-identity artefact.

## answer_b
Incidental

## explanation_b
Incorrect. An incidental parasite is a genuine parasite infecting a host species other than its ordinary one -- it is a real infection, not something mistaken for one.

## answer_c
Facultative

## explanation_c
Incorrect. A facultative parasite can live either freely or parasitically -- again a genuine organism, not an examination artefact.

## answer_d
Pseudoparasite

## explanation_d
Correct. A pseudoparasite is any artefact or non-parasitic object -- a plant fibre, a food particle, a free-living mite -- that could be mistaken for a genuine parasite. This mistaken identity happens specifically on microscopic examination of a specimen, when a look-alike structure resembles a true parasitic form. Recognizing pseudoparasites matters clinically, since treating one as a real infection would be an unnecessary intervention.

Incidental parasite in a wrong host

## question
Type of parasite that establish itself in a host which isn't his ordinary?

## subject
inf

## status

## answer_a

## explanation_a
Incorrect. An obligate parasite is defined by its inability to live outside a host, not by which host species it infects.

## answer_b
Incidental

## explanation_b
Correct. An incidental (accidental) parasite is one that establishes itself in a host species other than its ordinary one. ## answer_d
Pseudoparasite

## explanation_d
Incorrect. A pseudoparasite is a non-parasitic artefact mistaken for a real parasite, not a genuine parasite in an unusual host.

Coprozoic organisms pass through undigested

## question
Foreign species that pass through the alimentary tract without infectig the host?

## subject
inf

## status

## vignette

## answer_a

## explanation_a
Incorrect. An erratic parasite is a genuine infection that has wandered to an abnormal site within the correct host -- it is not a foreign species passing through undigested.

## answer_b
Coprozoic

## explanation_b
Correct. A coprozoic organism is a free-living, non-parasitic species from the environment. It passes through the human alimentary tract without infecting the host at any point. It is nonetheless found, still identifiable, in a stool sample, which is why it can be mistaken for a true parasitic finding if not recognized.

## explanation_c
Incorrect. An obligate parasite must live inside a host and could not survive as a free-living organism merely transiting the gut.

## answer_d
Facultative

## explanation_d
Incorrect. A facultative parasite can live freely or parasitically, but the stem describes an organism that never infects at all, which is the coprozoic pattern, not the facultative one.

Host that harbors the adult or sexual stage?

## subject

Definitive host

## explanation_a
Correct. The definitive (final) host harbours the parasite's adult or sexual reproductive stage. It is the host in which the parasite reaches full maturity. Sexual reproduction, when it occurs in the life cycle, always happens in the definitive host, never in an intermediate or paratenic host.

## answer_b
Intermediate host

## explanation_b
Incorrect. The intermediate host is where larval developmental stages take place, not the adult/sexual stage.

## answer_c
Paratenic host

## explanation_c
Incorrect. The paratenic host carries the organism in an arrested state of development, not the mature adult stage.

## answer_d
Transfer host

## explanation_d
Incorrect. A transfer host, like a paratenic host, merely carries the organism onward without hosting its adult reproductive stage.

Transfer host propagates the parasite onward

## question
An animal that propagates the parasite carrying it from one place to another?

## subject

This continues until the transfer host is eaten by, or otherwise reaches, a host in which development can resume or the definitive host is reached.
