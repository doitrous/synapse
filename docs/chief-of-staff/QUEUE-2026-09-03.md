## DISPATCH LESSON (2026-09-03) — batch papers on recycled banks
Exam banks recycle the same questions across papers/years, so a "23 papers untouched" module yields far fewer NEW questions than the count implies (ASU-CNS-3 paper1-2018 = 3 new / 49 dup). Two rules:
1. **Verify the EXACT frontier vs `git log`** before dispatch, not just the module — a CBF-103 lane wasted 40min re-authoring an already-landed page range.
2. For dup-heavy modules, brief the lane to **load all authored stems/concepts ONCE, then triage 3-4 papers in one pass** (amortize the dedup grep) rather than one-paper-per-lane.
